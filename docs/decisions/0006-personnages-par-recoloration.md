# 0006 – Personnages joueurs par recoloration

- **Statut** : acceptée
- **Date** : 2026-11-03

## Décision

Les personnages joueurs sont des variantes recolorées des planches existantes ; personnage modulaire plus tard.

## Pourquoi

Personnalisation dès la bêta sans dessiner ; les planches sont converties en couleurs indexées dès le départ.

## Alternatives écartées

Avatars canon (incohérents avec la narration) ; personnage modulaire (des mois de pixel art).
