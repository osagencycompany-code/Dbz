# 0002 – Serveur autoritaire

- **Statut** : acceptée
- **Date** : 2026-11-03

## Décision

Le client n'envoie que des intentions ; le serveur calcule dégâts, XP, butin et valide les positions.

## Pourquoi

Seule protection solide contre la triche dans un jeu en ligne.

## Alternatives écartées

Client de confiance (rejeté : triche immédiate).
