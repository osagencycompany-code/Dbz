# 0003 – Formules de stats

- **Statut** : acceptée
- **Date** : 2026-11-03

## Décision

Puissance = base de niveau B(L) × multiplicateur de spécialisation M(r), r = part des points de la stat sur tous les points gagnés au niveau.

## Pourquoi

Les formules à exposant sur les stats donnaient un écart de ×6,6 entre build spécialisé et équilibré ; ici l'écart reste autour de ×1,9. Calculer r sur tous les points gagnés évite qu'un point en Force baisse les PV.

## Alternatives écartées

Formules à exposant du premier document (rejetées) ; r calculé sur les points dépensés (rejeté : couplage entre stats).
